## 关于

Final Suspect 是 Among Us 原版的优质辅助模组，致力于为玩家带来更流畅、更丰富的游戏体验。作为原版核心机制的深度扩展，我们坚持「保留经典，优化体验」的开发理念，通过 20+ 项功能迭代，全面覆盖操作手感、视觉表现、社交互动等核心场景。\
要了解更多，请参阅我们的[官方网站](https://finalsuspect.pages.dev)。
